# figures

The paper's figures, one `.tex` file per figure, all drawn directly in LaTeX with TikZ/pgfplots; no external image files are used.
File names are `fig_<label>.tex`, and `\label{fig:<label>}` matches the file name; `main.tex` does not reference them directly: the section that uses a figure does `\input{figures/fig_xxx}`, in `sections/` for the manuscript and in `supplementary.tex` for the supplement.
Every number in a figure must come from a table already in the text or from an output file, under `../../outputs/` (regenerated by the commands in `../../README.md`) or `../../evidence/` (the public copy of the working folder `prechecks/`; see `../../evidence/PATHS.md`). A comment at the top of the file states the source (which table, which column), and the caption states it too. No new computation is done in a figure.
A new figure goes here, with one `\input` line in the corresponding subsection and one `\ref` in the text.

- `fig_threejob.tex` — Figure 1, §1: timeline of the three-job example; source: the arithmetic in the text of §1
- `fig_guard.tex` — Figure 2, §5.2: the guard wrapper and its charging, schematic; source: Algorithm 1 and the definitions in §5.2
- `fig_gap_harm.tex` — Figure S1, Supplementary S3.11: gap closed against harm for the guard variants and the comparators at the lightest load; source: the CSV fields named beside each series in the file
- `fig_gapvsg.tex` — Figure S2, Supplementary S3.12: gap closed against the promise G; source: the Gap closed column of Table S6 (`tab:s_guard`)
- `fig_excess.tex` — Figure S3, Supplementary S3.13: worst per-job excess, with and without the guard; source: the block headers of Table 7 (`tab:guard`) and Table S8 (`tab:s_adv`)
